# 退休請假月曆 PWA 安裝說明

## 1. 上傳到免費主機（擇一）
- **Netlify Drop**：到 app.netlify.com/drop，把整個資料夾拖進去，立即取得 https 網址。
- **Cloudflare Pages / GitHub Pages**：建立專案，上傳本資料夾所有檔案即可。

必須是 **https** 網址，Service Worker（離線功能）才會運作。

## 2. 在 iPhone 安裝
1. 用 **Safari** 開啟網址（要用 Safari，Chrome 不能加入主畫面）。
2. 點下方「分享」圖示 → 「加入主畫面」→ 「加入」。
3. 第一次請在**有網路**時開啟一次，讓 Tailwind、圖示、字型存進快取，之後即可離線使用。

## 3. 注意事項
- 排假資料與日薪**自動儲存在這個 App 內**；從 Safari 分頁開啟和從主畫面圖示開啟，兩邊資料是分開的。建議之後都從主畫面圖示開啟。
- 刪除 App 會一併刪除資料，換手機前請先用「匯出檔」備份，新手機再「載入檔」。
- 更新內容時，修改 `sw.js` 第一行的 `VERSION`（例如改成 `retire116-v2`），已安裝的 App 才會更新快取。
